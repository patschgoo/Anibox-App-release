# AniBox for Android

The phone and TV app for AniBox: your anime library from the AniBox sync folder, played with mpv,
progress shared with AniBox on the PC.

**Download:** [AniBox.apk](https://github.com/patschgoo/Anibox-App-release/releases/latest/download/AniBox.apk)
(on the Shield or another Android TV: the Downloader app with that address).

This is a **test version**. It installs as "AniBox (test)" and is signed with a public test key, so a later
version signed with a private key needs uninstalling this one first.

Each release also holds the app's source as a zip: AniBox for Android contains
[libmpv](https://github.com/jarnedemeulemeester/libmpv-android) (GPL-3.0-or-later), so the app as a whole
is distributed under GPL-3.0-or-later.
